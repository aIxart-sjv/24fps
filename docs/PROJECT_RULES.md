# 24FPS Project Rules

1. The SIH/NTRO requirements define the required feature scope.
2. The Backend Master Specification defines the backend architecture.
3. The Tech Stack document defines the selected implementation technologies.
4. Features must not be removed merely because they are difficult.
5. Implementation may be staged, but the final target is the complete SIH 26150 scope.
6. Do not invent unsupported forensic claims.
7. Preserve evidence integrity and provenance.
8. Prefer measurable validation over unsupported novelty claims.
9. Do not redesign the architecture without explicit approval.
10. The repository is the implementation source of truth.
